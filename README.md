## 📌 프로젝트 개요 (Overview)

**마케팅온 AI**는 마케팅에 많은 시간과 비용을 투자하기 어려운 카페, 음식점, 공방 등의 소상공인을 위해 개발된 **AI 기반 마케팅 자동화 대시보드**입니다.

매장의 업종과 날씨, 주요 이벤트 키워드만 선택하면 **SNS 홍보 문구, 카피라이팅, AI 배너 시안, 고객 리뷰 AI 자동 답글**까지 원클릭으로 생성하고 마케팅 일정을 관리해 줍니다.

---

## ✨ 핵심 기능 (Key Features)

### 1. 📊 마케팅 요약 대시보드 (Overview)
- **주요 KPI 시각화:** SNS 유입자 수, AI 콘텐츠 발행 건수, 반응률, 대시보드 활용 비용 절감액 제공
- **오늘의 AI 추천 미션:** 날씨 및 지역 데이터 기반 맞춤형 마케팅 미션 실시간 제안
- **성과 분석 그래프:** AI 콘텐츠 실행 전후 방문자 수 비교 추이 차트

### 2. 🪄 AI 콘텐츠 스튜디오 (Core Engine)
- **채널 맞춤 톤앤매너:** 인스타그램, 네이버 블로그, 당근마켓 최적화 문구 자동 작성
- **3초 원클릭 생성:** 캐치프레이즈, 본문, 해시태그 및 가상 AI 배너 시안 연동
- **바로 활용 가능:** 원클릭 전체 복사 및 캘린더 예약 기능 제공

### 3. 📅 스마트 마케팅 캘린더 (Marketing Calendar)
- 월별 주요 공휴일, 절기, 시즌 이슈(빼빼로데이, 연휴 등) 자동 안내
- 예약 포스팅 상태 관리 및 이벤트 스케줄링

### 4. 💬 AI 고객 리뷰 답글 도우미 (Customer Review AI)
- 네이버 지도, 카카오맵, 배달 앱 리뷰 감성/성향(긍정/부정) 자동 분석
- 단골 형성용 감동 답글 및 정중한 불만 대응 사과/개선 모범 답글 1초 만에 자동 생성

## 🖥️ 화면 구성 (Preview & Views)

1. **Dashboard Overview:** 성과 요약 및 오늘 AI 추천 미션
2. **AI Content Generator:** 채널별/톤앤매너별 마케팅 카피 및 배너 생성기
3. **Marketing Calendar:** 월간 프로모션 및 포스팅 예약 스케줄러
4. **AI Review Helper:** 고객 리뷰 성향 분석 및 AI 답글 템플릿 제안
5. **Analytics:** 마케팅 채널별 유입 비율 및 전환율 분석

## 🚀 실행 방법 (Getting Started)

별도의 백엔드 서버나 빌드 과정 없이 웹 브라우저에서 바로 실행할 수 있습니다.

```bash
# 1. 저장소 클론 (Repository Clone)
git clone https://github.com/your-username/marketing-on-ai.git

# 2. 프로젝트 폴더 이동
cd marketing-on-ai

# 3. index.html 파일 실행
# Chrome, Edge, Safari 등 원하시는 브라우저로 index.html을 열어주세요.
```
